# BENCHAMA101 Jersey Pre-order

เว็บพรีออเดอร์เสื้อ BENCHAMA101 2026/27 (FANCLUB / PLAYER / GOALKEEPER)

## โครงสร้าง
- `index.html` — หน้าเว็บทั้งหมด (ตั้งค่า `API_URL` ไว้ด้านบนของสคริปต์)
- `img/` — รูปเสื้อ ตราโรงเรียน และไอคอน
- `apps-script/Code.gs` — สำเนาโค้ด Google Apps Script (ต้องวางและ deploy ใน Google เอง)

## การอัปเดตเว็บ
1. แก้ไขใน branch แยก แล้วเปิด Pull Request
2. ตรวจดูการเปลี่ยนแปลง แล้วกด **Merge** → เว็บจริงจะ deploy อัตโนมัติ
